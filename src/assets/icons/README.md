# Extension icons

Generated from the Website Toolkit brand logo.

| File | Use |
| --- | --- |
| `icon16.png` | Toolbar (Chrome/Firefox) |
| `icon32.png` | Toolbar / Windows |
| `icon48.png` | Extensions management page |
| `icon128.png` | Install dialog / Chrome Web Store listing icon |

Small sizes use the **graphic only** (browser + magnifying glass). Wordmark is omitted because it is unreadable at 16–48px.

Full logo assets for store listings live in `../store/`.

To regenerate from the source logo:

```bash
python3 scripts/generate-icons.py /path/to/logo.png
```
